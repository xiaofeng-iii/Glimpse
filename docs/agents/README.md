# Agent Context

本目录只存放供 AI 与自动化工具长期复用的项目上下文，例如领域词汇、稳定约束
和跨模块协作说明。

- 通用且简短的工作规则优先写在根目录 `AGENTS.md`。
- 只有内容过长或需要独立维护时，才在本目录新增文件。
- 临时计划、分析、提示词和工具输出放在项目根目录 `.tmp/`，不得放在这里。

## 前端 UI 开发

写或改任何前端 UI 之前，先过两份文档：

- [`ui-checklist.md`](./ui-checklist.md) —— 动手前 30 秒核对清单：重要性分级、
  组件复用、高度档位、与邻居比对、真实内容验证。
- [`ui-components.md`](./ui-components.md) —— 组件选型速查表：弹层/按钮/输入
  控件该用哪个现成零件，以及尺寸、圆角、z 档位指向。

两者的判断依据都追溯到根目录 `DESIGN.md`，数值一律以
`glimpse-frontend/src/styles/main.css` 为唯一事实源。
